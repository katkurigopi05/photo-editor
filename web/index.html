Get started

One command for everything

The unified entry point covers a single image, a folder, a GIF, a video, building an animation from stills — or launching the GUI.

app.py
# install the core (the GUI also needs Tkinter)
pip install -r requirements.txt

# edit a single photo with a saved recipe
python app.py image look.json photo.jpg out.png

# apply that same recipe to a folder, a GIF, and a video
python app.py batch look.json in_dir/ out_dir/
python app.py gif   look.json in.gif  out.gif
python app.py video look.json in.mp4  out.mp4

# build an animation from still images
python app.py build slideshow.gif a.jpg b.jpg c.jpg --duration 500

# launch the desktop editor · list every operation
python app.py gui
python app.py list-ops
