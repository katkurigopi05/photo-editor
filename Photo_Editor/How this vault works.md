# How this vault works

This folder is an [Obsidian](https://obsidian.md) vault: plain Markdown notes
linked with `[[wikilinks]]`. It mirrors the source-of-truth docs under
[`docs/`](../docs) but as an interlinked knowledge graph.

- **Home:** [[Project Director]] is the map of content.
- **Atomic notes:** each concept, type, package, crate, phase, and decision has
  its own note.
- **Tags:** `#concept`, `#data-model`, `#package`, `#crate`, `#phase`, `#adr`,
  `#rule` group related notes.
- **Graph view:** `Cmd/Ctrl+G` shows the whole knowledge graph.

Notes here summarize and link; the authoritative, versioned docs remain in
[`docs/`](../docs) and the code.
